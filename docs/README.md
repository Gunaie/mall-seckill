## 快速开始

1. 先把项目跑起来：根目录 `docker compose up -d`，访问 http://localhost:8090，文档 http://localhost:8090/doc.html
2. 按文档 01 → 03、06 → 07 顺序学习，每篇末尾有自测清单
3. 用文档 07 的专项问答做面试前自测
4. 简历写法：突出「六级漏斗 + RocketMQ 事务消息 + 8 分片 + 2k QPS」，数据与 [benchmark-report-v2.md](../benchmark-report-v2.md) 保持一致
